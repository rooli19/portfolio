# My Portfolio

I built this portfolio to share my projects and show how I approach problems as a developer. I went with a scrapbook style because I wanted it to feel like a collection of work I could flip through.

## Tech Stack

- **React** for pages and reusable components
- **Vite** for local development and production builds
- **CSS** for layouts, paper textures, and handwritten details
- **Motion** for the hanging ID badge, digicam, and scroll animations
- **GitHub Actions and GitHub Pages** for deployment

## How I Built It

I organized the site into Home, About, Works, and Contact pages. I made reusable components for things like project cards and screenshot galleries.

I built a separate scrapbook case study for TranspoGAPO to walk through the research, design, and implementation. My other projects use a shared layout with a short overview and a screenshot carousel.
